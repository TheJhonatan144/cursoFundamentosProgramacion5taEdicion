# Bootcamp Programación de Cero a POO 
## Descripción 
Este repositorio corresponde al bootcamp **“Programación de Cero a POO”**, un 
curso virtual en vivo orientado a estudiantes que están iniciando en programación y 
desean construir una base sólida antes de avanzar hacia Programación Orientada a 
Objetos. 
El enfoque del bootcamp sigue una progresión académica práctica: 
**lógica de programación → diagramas → pseudocódigo → C++ estructurado → Java 
POO**. 
A lo largo del curso, se trabaja con clases en vivo, ejercicios prácticos, tareas 
autónomas, evaluaciones y proyectos integradores, manteniendo siempre una 
metodología centrada en comprender primero la lógica, luego representarla y 
finalmente implementarla en código. 
## Objetivo del repositorio 
Este repositorio tiene como finalidad organizar y almacenar el material, ejercicios, 
prácticas y proyectos desarrollados durante el bootcamp, además de servir como 
evidencia del proceso de aprendizaje mediante el uso de Git y GitHub. 
## Contenido del curso 
Hasta este punto del bootcamp, se han trabajado temas como: - lógica y resolución de problemas - diagramas de flujo - pseudocódigo en PSeInt - introducción a C++ - variables, operadores y entrada/salida - estructuras condicionales - estructuras repetitivas - arreglos - funciones y modularización - depuración y corrección de errores - introducción a Git y GitHub 
- preparación de mini-proyecto en C++ 
## Estructura del repositorio 
La estructura puede variar según el avance del curso, pero en general este repositorio 
puede incluir elementos como: - `clases/` → material de apoyo o recursos vistos en clase - `ejercicios/` → ejercicios desarrollados en las sesiones - `tareas/` → tareas enviadas para práctica autónoma - `proyectos/` → mini-proyectos o trabajos integradores - `README.md` → presentación general del repositorio 
## Metodología de trabajo 
Durante el bootcamp se promueve un flujo de trabajo ordenado. Esto incluye: - desarrollar ejercicios y proyectos de forma progresiva - registrar avances mediante commits - publicar cambios en GitHub - mantener estructura clara en los repositorios - documentar de forma básica los proyectos mediante README 
El objetivo no es solo llegar a un resultado final, sino también evidenciar el proceso de 
construcción del trabajo. 
## Herramientas utilizadas 
Durante el curso se utilizan principalmente las siguientes herramientas: - **PSeInt** para pseudocódigo - **Visual Studio Code** como editor principal - **Git** para control de versiones - **GitHub** para repositorios y evidencias - **C++** como lenguaje principal en la etapa estructurada - **Java** para la etapa posterior de Programación Orientada a Objetos
