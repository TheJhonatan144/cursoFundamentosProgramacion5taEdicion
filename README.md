# Bootcamp Programacion de Cero a POO - 5ta Edicion
## Descripcion 
Este repositorio corresponde al bootcamp **Programacion de Cero a POO 5ta Edicion**, curso virtual en vivo orientado a estudiantes que estan iniciando en programcion y desean construir una base solida antes de avanzar hacia temas mas complejos.

El enfoque del bootcamp sigue una progresion academica practica: 
**logica de programamacion - diagramas - pseudocodigo - C++ estructurado - Java POO**

A lo largo del curs, se trabaja con clases en vivo, ejercicios practicos, tareas atonomas, evaluaciones, proyecto, manteniendo siempre una metodologia centrada en comprender primero la logica, luego representarla y finalmente implementarla en codigo.
